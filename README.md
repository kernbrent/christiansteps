# christiansteps
Christian Steps Ministries Web Site

### Income form fields by income type

The Add income or invoice and Edit income forms show donor email only for Donation. Donation hides and disables Client, Project, Invoice number, Invoice date, Due date, and Invoice amount; enter a new donation using Amount received now. Editing a donation preserves its saved amount. Other income and Earned income show the optional invoice fields and hide and disable donor email. Switching types preserves draft values until saving, but inactive fields are omitted from submission. Existing invoice-required validation still applies to non-donation income. No schema change is required.
